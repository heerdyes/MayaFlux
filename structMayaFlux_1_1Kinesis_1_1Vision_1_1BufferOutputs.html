Detailed Description

Live device views of the GPU-resident export buffers, one named slot per exporting op, populated only when its own export flag was set.

Null/default otherwise. The executor owns the memory: each view is valid for one more run before its buffer is reused.

tracks/keypoints decode via VisionGpuExecutor::read_exported_tracks()/ read_exported_keypoints(). labels is ConnectedComponents' per-pixel compact label map (one uint32 per pixel, 0 background, 1..count foreground, matching component_boxes/Contour::label_id), consumed via VisionGpuExecutor::select_label() rather than decoded to a host list. contours decodes via read_exported_contours(); see ContoursBufferView.
