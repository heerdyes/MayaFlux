std::optional< ImageFormat > MayaFlux::Portal::Graphics::TextureLoom::readable_format ( const std::shared_ptr< Core::VKImage > & image)
staticnodiscard

ImageFormat of an image that can be read back as one flat block.

Requires an initialised 2D image of one layer and depth 1 with a transfer-source usage, a format with an ImageFormat mapping that is not combined depth-stencil, and a nonzero base level that fits the image's allocation. The base level's byte count is calculate_image_size(width, height, 1, format).

Checks structure only: it says nothing about the image's current layout or whether anything has been written to it.

Returns
The format, or nullopt when any requirement is not met.
