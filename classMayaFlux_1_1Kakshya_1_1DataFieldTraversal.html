Detailed Description

template<FieldArray Array>
class MayaFlux::Kakshya::DataFieldTraversal< Array >

On-demand windowing and field operations over an indexed array.

A traversal maintains an independent position and batch size without owning the array. Field projection is available when the array and its slices provide to_nddata<T>(field_name). The same traversal works with any FieldArray; neither it nor the array needs to name a concrete record format.

Usage:

DataFieldTraversal traversal(items, 64);
while (!traversal.at_end()) {
auto scores = traversal.window_to_nddata<double>("score");
traversal.for_each_in_window([](const auto& item) {
auto name = item.text("name");
});
traversal.advance();
}
