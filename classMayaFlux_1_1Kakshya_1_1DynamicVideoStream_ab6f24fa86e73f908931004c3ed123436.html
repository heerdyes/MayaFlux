std::shared_ptr< DynamicVideoStream > MayaFlux::Kakshya::DynamicVideoStream::snapshot ( uint64_t frames) const
nodiscard

Copy the most recent frames into a new linear stream, oldest first.

Frames that have already been overwritten come out black. The copy is independent of this stream.

Parameters
framesFrames to keep, capped at the ring capacity, or at the frames written for a linear stream.
Returns
New stream with the same size, format and rate, or null if empty.
