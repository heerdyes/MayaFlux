9/**
10 * @class FrameSeekProcessor
11 * @brief FrameAccessProcessor whose read position follows a function of time.
12 *
13 * The video counterpart of the time-mapped read in CursorAccessProcessor. With a
14 * time map set, each process() call advances a clock by 1 / global fps seconds and
15 * reads the frame the map points at, so scrub, freeze, reverse, a tap trailing a
16 * live DynamicVideoStream (TimeMaps::lagged with the stream's frame rate) and
17 * stutter all work on video. Without a map it behaves exactly like
18 * FrameAccessProcessor.
19 *
20 * The map takes seconds since the last reset() and returns a position in frames.
21 * Positions wrap inside the loop region when the container loops, and are held at
22 * the first or last frame otherwise.
23 */
24class MAYAFLUX_API FrameSeekProcessor : public FrameAccessProcessor {
