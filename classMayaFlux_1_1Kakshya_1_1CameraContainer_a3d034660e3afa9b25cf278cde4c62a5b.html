uint8_t * MayaFlux::Kakshya::CameraContainer::mutable_frame_ptr ( )
nodiscard

Mutable pointer into m_data[0] for the caller to write decoded pixels.

Mirrors VideoStreamContainer::mutable_slot_ptr() for ring mode, but operates on the single flat-mode frame. The caller (the registered CameraSource) writes width * height * channels bytes at this address, then calls mark_ready_for_processing(true).

Returns
Pointer to the start of the frame pixel buffer, or nullptr if the container is not properly initialised.
