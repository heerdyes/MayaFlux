nodiscard

Broadcast of what fn returns, taken once per graphics frame.

Adds a routine to scheduler that calls fn every graphics frame and signals each value it returns, registered under name. The routine ends once nothing holds the returned source, or when the task is cancelled.

auto results = Kriya::frame_results<Result>(*scheduler, [state]() -> std::optional<Result> {
return state->try_finish();
});
event_manager->add_event(std::make_shared<Vruta::Event>(
Kriya::on_signal(results, [](const Result& r) { })));
