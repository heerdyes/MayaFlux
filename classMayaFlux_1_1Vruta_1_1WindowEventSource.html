Detailed Description

Awaitable stream of window input events.

Signals are produced by the window backend's poll(), on the polling thread. Coroutines suspend via WindowEventAwaiter and are resumed synchronously from signal(). Tracks input state for immediate polling via is_key_pressed(), is_mouse_pressed(), and get_mouse_position().
