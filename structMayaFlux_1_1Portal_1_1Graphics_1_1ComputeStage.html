Detailed Description

One pipeline dispatch within a ComputePress::record_sequence call.

Bundles everything needed to bind a pipeline, push constants, dispatch, and determine the barrier owed to the next stage in the sequence. Pipeline and descriptor sets must already exist (created via create_pipeline / allocate_pipeline_descriptors) — this struct only describes how to use them within a recorded sequence, it does not own their lifetime.
