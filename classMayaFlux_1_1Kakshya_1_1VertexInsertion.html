Detailed Description

Write counterpart to VertexAccess: splits interleaved vertex bytes into typed channels.

Parallel to MeshInsertion and DataInsertion: holds a mutable reference to a channel list and populates it. Each VertexLayout attribute becomes one DataVariant, in layout order, holding the attribute for every vertex:

VERTEX_POSITIONS_3D, NORMALS_3D, TANGENTS_3D, COLORS_RGB -> vector<glm::vec3> TEXTURE_COORDS_2D -> vector<glm::vec2> VERTEX_COLORS_RGBA -> vector<glm::vec4> SCALAR_F32 -> vector<float>

For the canonical point, line and mesh layouts the channel order matches the slot order as_point_vertex_access() and its siblings consume, so a read channel list can be written back without reordering.

Nothing is written unless the layout and byte count are both valid.

Usage:

std::vector<DataVariant> channels;
VertexInsertion ins(channels);
if (ins.insert_interleaved(bytes, layout)) {
auto& positions = std::get<std::vector<glm::vec3>>(channels[0]);
}
