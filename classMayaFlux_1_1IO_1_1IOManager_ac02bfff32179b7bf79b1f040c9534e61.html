uint32_t MayaFlux::IO::IOManager::capture_output ( const std::string & filepath,
AVCodecID codec_id = AV_CODEC_ID_NONE )
nodiscard

Begin continuous capture of live audio output to a file.

Registers an observer with AudioBackendService. Each output cycle the observer drives an AudioOutputContainer and posts its processed_data to a SoundFileWriter. Returns an opaque capture id for use with stop_audio_capture().

Returns 0 and logs an error if AudioBackendService is unavailable.

Parameters
filepathOutput file path.
codec_idEncoder override; AV_CODEC_ID_NONE = container default.
Returns
Capture handle; pass to stop_audio_capture() to finalise.
