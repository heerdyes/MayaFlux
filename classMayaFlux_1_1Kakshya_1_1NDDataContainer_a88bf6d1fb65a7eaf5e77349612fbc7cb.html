ValueT MayaFlux::Kakshya::NDDataContainer< T >::get_value_at ( const std::vector< uint64_t > & coordinates) const
inlinenodiscard

Read a single element at the given N-dimensional coordinates.

Returns a default-constructed ValueT on coordinate out-of-range or type mismatch. No conversion is performed: ValueT must match the container's native element type (query value_element_type() first when the type is not statically known).
