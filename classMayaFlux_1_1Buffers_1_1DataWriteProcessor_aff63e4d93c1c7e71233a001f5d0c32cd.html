void MayaFlux::Buffers::DataWriteProcessor::write_field ( std::string name,
Kakshya::DataVariant data )

Write a named field of the attached buffer.

A VolumeGridBuffer field is written through seed_raw, and a NetworkGeometryBuffer state field into the slot its next stage reads. The data size must equal the field's byte size.
